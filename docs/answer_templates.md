# SC Search 玩家回答模板（供宿主 Agent 按需参考）

适用前提（见 [AGENTS.md](../AGENTS.md)）：**事实严、方案放开**。

- 所有硬事实（数值、价格、手续费、冷却、店名、材料、版本）只能来自本地 MCP 证据；缺失或有单位争议就诚实说明，`stale=true` 标注快照版本但不喧宾夺主。
- 所有模板共同骨架：**一行粗体结论先行 → 库内实证 → 可执行路线/对比/步骤 → 实操避坑（优先引用 [TIPS.md](../TIPS.md)）→ 可选下一步细化**。
- 按问题复杂度裁剪，简单单字段题（如「卡拉克货舱多大」）不必强套整张模板。

适用：武器 / 护盾 / 量子引擎搭配；遵守 `browser.wait_confirm=true` 门禁。

## 7. 客户端报错 / 汉化 / 账号问题

适用：30009、EAC 报错、进不去游戏、汉化失效。

```markdown
**结论：{最可能原因 + 先试代价最小的一招}**

### 排查顺序（由轻到重）
1. **1 分钟排查**：重启启动器 / 登出重登 / 切地区服务器
2. **中度排查**：Verify 校验 / 清 Shaders 或 USER 缓存
3. **兜底**：Character Repair（角色修复）或查阅 RSI 官方帮助页

### 别踩的坑
- 误删整目录丢失键位、角色修复冷却等
```
