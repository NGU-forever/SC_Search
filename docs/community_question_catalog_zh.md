## 对 SC_Search 产品的含义

### 已对齐的优势区
- 中文俗称 → 实体（船/货/势力/蓝图）
- 商品买卖价、飞船静态参数、蓝图材料+任务池、势力任务列表、数据新鲜度

### 最大缺口（社区问得最多但库答不好）
1. **操作/找路/叫船/按键**（教程类）  
2. **客户端报错与账号体系**  
3. **「当前版本最优赚钱」时效攻略**  
4. **游戏内船店 aUEC 购点完整表**（部分第三方有，库未 ingest）  
5. **矿点 / RS / 精炼最优方案**（需外部站或浏览器）  
6. **活动本逐步流程**

### 建议后续题库抽样（可直接喂 `sc_answer`）
1. 铝哪里买最便宜？  
2. 量子矿哪里卖？  
3. 红风物流有哪些任务？  
4. 视差步枪蓝图材料和任务？  
5. 卡拉克货舱多大？  
6. 锤头鲨游戏里多少钱？  
7. FS-9 哪里弄？  
8. 鼹鼠怎么配采矿头？（应走 mining_calc）  
9. 泰坦怎么配打炮？（应走 loadout_calc）  
10. 进不去游戏报错 19000？（应诚实降级）
